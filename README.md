# Git and GitHub Assignment
Overview

This repository demonstrates a basic Git workflow: creating a local repository, tracking files, committing changes, connecting to GitHub, and pushing the work to a public remote repository.
Project Contents
- sample_data.py — Python script that creates a small sample dataset.
- sample_data.csv — generated by running the Python script.
- README.md — project description and instructions.
Requirements
- Python 3 installed
- Git installed
- A GitHub account
Run the Script
From the project folder, run:
python sample_data.py
The script creates sample_data.csv containing five sample student records.
Basic Git Workflow

Run these commands in the project folder:
git init
git add README.md sample_data.py
git commit -m "Add sample data script and README"
git add sample_data.csv
git commit -m "Add generated sample dataset"

Create a public repository on GitHub. If you have not created a README on GitHub, leave that option unchecked to avoid a merge conflict. Then connect and push your local repository (replace the URL with your own repository URL):
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
To view your commit history:
git log --oneline
Take a screenshot of the terminal output showing at least two commits and include it in your assignment evidence if required.
